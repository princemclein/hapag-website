# Hapag

> A modern Filipino restaurant landing page built with HTML, CSS, and Vanilla JavaScript.

---

## Project Goal

Hapag is a responsive restaurant landing page that showcases authentic Filipino cuisine through a clean and modern interface. The website allows visitors to browse the restaurant's menu, discover featured dishes, learn about the restaurant, and find contact information.

This project focuses on frontend development and does not include backend functionality such as online ordering or payment processing.

---

## Target Users

- People who enjoy Filipino cuisine
- Customers looking for a place to dine
- Visitors exploring the restaurant's menu online
