# Hapag Restaurant

A modern single-page restaurant website showcasing Filipino cuisine, designed with a warm and inviting visual style.

> Enjoy handcrafted Filipino dishes made with fresh ingredients, warm hospitality, and flavors that bring families together.

## 🔗 Live Demo

[Visit Hapag Restaurant](https://hapag-restaurant.vercel.app/)

## ✨ Features

* **Single-page website** with smooth navigation
* **Home section** introducing the restaurant
* **About section** showcasing the restaurant
* **Menu section** with food selections
* **Menu filtering** by categories such as:

  * Food
  * Beverages
  * Desserts
  * And more
* **Contact section** for restaurant inquiries
* **Contact form** for sending messages
* Responsive design for different screen sizes

## 📌 Sections

* Home
* About
* Menu
* Contact

## 🎯 Purpose

Hapag was created as a web development project to practice building a complete restaurant website with an organized layout, interactive menu filtering, and a functional-looking contact experience.
